# スノーグリル ❄️🐻‍❄️🍖

広告でよく見る「白クマを倒して肉を焼き、凍えた人に配る」タイプの放置系アクションゲーム（アイドルアーケード）です。

1. 画面のどこでも押してドラッグ → その方向に歩く
2. 白クマに近づくと自動で斧を振る。倒すと生肉が落ちて、背中に積み上がる
3. グリルの「生肉を置く」エリアに入ると肉を置く → 自動で焼ける
4. 「焼けた肉」エリアで肉を取り、配給台の「配る」エリアへ
5. 凍えた人が肉を食べてお金を払う → お金を拾う
6. 光っている円の上に立つとお金を払って設備を解放（グリル2台目・バックパック・助っ人ハンター・運び係・斧の強化・配給台2つ目・キャンプファイヤー・狩り場拡張…）

**遊ぶ:** https://machino-ai.jp/snow-grill/

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面・HUD・スタート画面 |
| `js/config.js` | **調整値はここ**（速さ・白クマ・グリル・お客さん・解放の値段と順番・マップ配置） |
| `js/game.js` | ゲーム本体（移動・攻撃・肉の受け渡し・お客さん・助っ人・描画） |
| `js/audio.js` | 効果音と BGM（WebAudio で生成） |
| `img/` | ゲームで使う軽い画像（`tools/optimize.py` で `assets/` から生成） |
| `assets/` | ChatGPT で作った素材の原本（`_sheets/` は生成されたままのシート） |

`index.html?reset` で最初からやり直せます（セーブ消去）。PC ではキーボード（WASD / 矢印）でも動けます。

## 2台のPC（メインPC / 4thPC）で共同編集する手順

最初の1回だけ（4thPC）：

```bash
gh repo clone mitsukenn/snow-grill
```

毎回：作業前に `git pull`、作業後に `git add -A` → `git commit -m "変更内容"` → `git push`。
