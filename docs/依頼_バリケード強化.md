## オーナーの指定

- **強化ショップの項目にはしない**
- **フロアに出てくる要素**にする（床のパッドに立ってお金を払う、今の設備の解放と同じ形）

## 今のコード（main 時点）

- バリケードは `js/config.js` の `unlocks` に `{ id: 'barricade', price: 45, x: 460, y: 690 }`。建てると `G.barricade = true`
- 耐久は固定。ふつうの村は `raid.fenceHp = 260`、決戦は `fenceHp = 420`（`js/game.js` の 195行・317行あたり）
- こわれたら柵の前に立ち、お金で修理する（`repairSpot`。`js/game.js` 638行、`js/battle.js` 325行あたり）
- 強化ショップ（`config.js` の `upgrades`）は斧・体力など9項目。バリケードは入っていない

## 案（細かいところは作業する側で決めてよい）

- バリケードを建てたあと、柵の近くの床に「バリケード強化」のパッドが出る。払うと耐久が上がる。段が上がるほど値段も上がる
- 段ごとに見た目を変える（木 → 石 → 鉄など）。強くなったのが目で分かるように
- 決戦のバリケード（はじめから立っている分）にも強化の段を効かせるかは、遊んでみて判断
- 段は SAVE に残す。上限は3〜5段くらい。前に「白クマ +1 の繰り返し解放はやめた」ので、パッドが出続けてうるさくならないように
